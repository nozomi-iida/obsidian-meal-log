# プロダクト概要

Web アプリから食事を記録し、Obsidian で集計・振り返るための**記録専用**アプリ。

vault（`obsidian-vault`）はすでに GitHub にあり、obsidian-git で PC・スマホと同期している。
このアプリの役割は、その vault の `Meals/items/` に **Markdown ファイルを 1 つ置くこと**だけ。

```
Web アプリ（Vercel）
    ↓ GitHub Contents API で .md を commit
GitHub: obsidian-vault リポジトリ
    ↓ obsidian-git が pull
PC・スマホの vault フォルダ
    ↓
Obsidian（Bases / Dataview で集計）
```

## 中核となる機能

- **プリセットからの記録** — 定番メニュー（`Meals/presets.md`）を選び、量を調整して送信する
- **Markdown の生成とコミット** — 決まった frontmatter 形式のファイルを
  `Meals/items/YYYY-MM-DD-HHmm.md` として新規作成する

## 主な利用シーン

1. テンプレートから選ぶ
2. 量の数字を必要に応じて調整する
3. 送信する

利用者は本人ひとり。外出先のスマホから記録するため、デプロイして使う。

## スコープ外（将来の拡張）

### 写真からの記録

外食時に写真を撮り、食材と量を推定してカロリー・タンパク質を出すフロー。
**初期リリースには含めない。**

1. 写真を撮る
2. 写真からカロリー・タンパク質を出す
3. 量の数字を必要に応じて調整する
4. 送信する

現状この用途は `.claude/commands/meal.md` 経由で Claude Code が画像を読んで賄っている。
データ形式を今から写真向けに縛ることはしない。追加する時点で必要なら形式を見直す。

## 記録するデータの形

**1 食 1 ファイル**。ファイル名は食べた時刻（`YYYY-MM-DD-HHmm.md`）。

```markdown
---
date: 2026-09-05
time: 21:00
meal: 夜
dish: 鍋
menu: 白米300g / 鶏もも400g / 木綿豆腐150g / 野菜
kcal: 1140
protein: 98
foods: [白米, 鶏もも, 木綿豆腐, 野菜]
---

- 白米 300g — 468 / P7.5
- 鶏もも 400g — 452 / P76
```

| プロパティ | 役割 |
|---|---|
| `date` | 日付。集計の軸 |
| `time` | 食べた時刻（`HH:mm`）。並び順を決める |
| `meal` | 朝 / 昼 / 夜 / 間食 / 寝る前。時刻から推定して入れる |
| `menu` | 量つきのサマリー。一覧で数字の根拠を読むための列 |
| `kcal` / `protein` | その食の値。単位は書かず数値のみ |
| `foods` | 食材名のリスト。量を含めず正規化する。絞り込み・集計用 |
| `dish` | 料理名（鍋・野菜炒めなど）。省略可 |
| 本文 | 食材ごとの kcal 内訳。後から人が数値を直せるようにする |

`menu` と `foods` は一見重複しているが用途が逆。`menu` は**読む用**（量が入るぶん読みやすい）、
`foods` は**絞る用**（正規化されているぶん集計しやすい）。

## 設計上の立場

### 集計機能を持たない

日次・月次の合計は Obsidian の Bases と Dataview が、ノートを開くたびに vault を
スキャンして算出する。`.base` ファイルは集計結果ではなく**クエリの定義**（SQL の VIEW に近い）で、
結果はファイルに保存されない。

したがってアプリ側に集計処理もサマリー更新処理も要らない。
**正しい形のファイルを置けば、日次も月次も勝手に出る。**

### 書き込みは常に新規作成

ファイル名を食事区分ではなく時刻にしたことで、同じ区分を 2 回食べても衝突しない。
結果として「既存を読む → マージ → 書き戻す」が不要になり、
**存在チェックなしの `PUT` 1 発**で完結する。sha 競合も、合計値の再計算バグも発生しない。

### 精度より継続

厳密な栄養管理が目的ではなく、**月末に「タンパク質が足りていたか」を数字で振り返れること**が目的。
迷ったら概算で書いて先に進む。数値は後から本文の内訳を見て手で直せる。
（体重 82kg、タンパク質目標 131〜180g/日）

## 前提となる vault 側の資産

| パス | 役割 |
|---|---|
| `Meals/presets.md` | 定番メニューと食材の概算値。**アプリは読まない**（同じ内容をアプリ側に持つ） |
| `Meals/items/` | 食事ログの保存先 |
| `Meals/photos/` | 写真の保管先。初期スコープでは使わない |
| `Meals/食事管理.base` | 横断的な一覧・絞り込みビュー |
| `.claude/commands/meal.md` | Claude Code から記録する既存運用。Web アプリ完成後は使わない |

食材名は `presets.md` の表記に揃える。表記ゆれ（「鶏もも」「鶏もも肉」）を防ぐため、
アプリ側では自由入力ではなく選択式にする。
